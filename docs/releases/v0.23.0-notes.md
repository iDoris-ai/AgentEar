## v0.23.0 —— Qwen3-ASR：设置窗口里一键下载，菜单栏切常驻

默认的语音识别**没变**，仍是随包的 SenseVoice。这一版把 Qwen3-ASR 做成了
**点一下就能用**的可选项：不用再自己装 brew、不用改配置文件。

### 怎么用

1. 菜单栏 → **设置…** → **语音识别** 下拉框，选 `Qwen3-ASR 0.6B` 或 `Qwen3-ASR 1.7B`。
2. 没下过的话，会先下载（窗口里有进度「312 / 713 MB」，可以取消、之后继续）。
   **装好、校验、试跑通过之后才自动切过去**——下载的这几分钟里，识别照样用 SenseVoice，不会丢字。
   下载期间你改选了别的，它装完就不切。
3. 想更快：菜单栏勾上 **「Qwen3-ASR 常驻」**。每句话快约 1.6 秒，代价是一直占着内存；
   空闲 10 分钟自动退出、把内存还回去。**点一下立刻生效**，方便你对比两种形态。

### 两档 × 两形态（本机实测，`docs/benchmarks-asr-zh-en.md` §9）

| | 每句耗时（热态） | 占内存 |
|---|---|---|
| SenseVoice（随包，默认） | 0.13–0.39 s | 约 0.3 GB（只在转写时） |
| Qwen3 0.6B 逐次（**Qwen3 的默认**） | 1.8–2.0 s | 约 0.8 GB（只在转写时） |
| Qwen3 0.6B 常驻 | **0.09–0.35 s** | 约 0.8 GB（一直占着） |
| Qwen3 1.7B 逐次 | 1.9–2.5 s | 约 2.4 GB（只在转写时） |
| Qwen3 1.7B 常驻 | **0.19–0.69 s** | 约 2.4 GB（一直占着） |

⚠️ 这张表只量了**速度和内存**（用的是合成语音）。**准确率**看 T3.5.1 的横比：
1.7B 在英文、中英混说上比 SenseVoice 准；0.6B 与 SenseVoice 基本持平。
常驻形态的准确率没有重跑完整语料——没有证据表明它更差，但也还没证明「完全一样」。

Qwen3 里默认选 **0.6B、逐次调用**：这是按「默认小内存」定的，你可以随时改。
（以前自己 `brew install speech` 用过 Qwen3 的，升级后仍是 1.7B，行为不变。）

### 下载了什么、放在哪

- **speech-swift v0.0.28**（上游的预编译包，99 MB，Apache-2.0）：版本**钉死**，
  sha256 校验，解包到 `~/.agentear/models/qwen3/runtime/`，并去掉 macOS 的隔离标记。
- **模型权重直接从 Hugging Face 下**（0.6B 约 713 MB、1.7B 约 2.47 GB），
  钉在固定的版本（commit），逐个文件 sha256 校验。**都不打进 AgentEar 的安装包。**
- 语音识别程序**一律在「禁止联网」的沙箱里运行**：模型由我们下载、校验过的那份才用，
  它不会背着你再去网上拉东西。

### 顺带修的

- **下载模型时退出 AgentEar，下载进程不跟着退**（泰语模型也有这个问题）：
  它会在后台继续写半截文件，下次启动时两个下载同时写一个文件。现在退出、被 kill、
  重启三种情况都会把下载进程一起收掉（下过的部分保留，下次接着下）。
- 常驻服务被异常留下（AgentEar 被强制结束）时，下次启动会自动收掉，不会一直占着内存。

### 命令行（排障 / 预下载）

```bash
agentear --fetch-qwen3 0.6b     # 预下载（只装不切）；1.7b 同理
agentear --diagnose             # 多了一节 Qwen3-ASR：运行时 / 两个模型装没装好
```

### 验证

- `cargo test` 全绿（新增：清单自洽、tag↔模型反推、下拉框选中逻辑、空闲回收真值表、
  孤儿进程识别不误杀、配置默认值与老用户迁移、状态文案覆盖每种状态）；三处变异都会让新测试变红。
- 本机实测：从零下载运行时 + 0.6B（137 秒）；1.7B 校验安装；下载中断后断点续传；
  两档 × 两形态转写正确；同一进程里切换即时生效；SIGTERM / SIGINT / 退出菜单后
  不留下 speech-server 和下载进程；被 kill -9 留下的服务下次启动被收掉；空闲 60 秒后自动退出。

### ⚠️ 没测到的（需要你手测）

- **设置窗口和菜单栏的真实点击**（后台环境点不了界面）：
  1. 设置…→ 语音识别 选 `Qwen3-ASR 0.6B` → 看进度走完 → 下拉框停在 0.6B、状态「已安装」；
  2. 按右 Command 说一句，看转写是不是 Qwen3 的风格（数字会写成「三十二」而不是「32」）；
  3. 菜单栏勾「Qwen3-ASR 常驻」，再说几句，体感应当明显变快；取消勾选后再说，回到约 2 秒；
  4. 下载途中点「取消」，再点「继续下载」应当从断点接着下。
- 泰语界面的新文案没有母语者校对。
