# v0.9.0 —— 语音指令表:说一句就干活

说一句**你自己声明过的短语**,本机直接干活,**不等模型**:

```
「记一下 明天要测 AEC」      → 存一条笔记
「搜索 talk.rs」            → 打开浏览器搜
「搜索 github rust async」   → 走 GitHub 搜索(比「搜索」长的短语优先)
「发邮件给 a@b.com」         → 打开一封草稿(不是替你发出去)
「说粤语」/「切换到对话模式」  → 切音色 / 切模式
```

**没命中就照常走对话模式的 LLM 路** —— 开放式的句子本来就该由模型理解,
指令表只认你声明过的那几条。所以**说不中也不会坏事**,只是多花一次模型调用。

## 它怎么工作

**两段式:本地表先查,没命中再问模型。**

| | 本地指令表 | LLM |
|---|---|---|
| 触发 | 句子以某个**已声明短语**开头(去标点、归一大小写) | 其余一切 |
| 耗时 | 0ms,**断网也能用** | 一次模型调用 |
| 能干什么 | 下面那三种封闭动作 | 开放式对话 |

表在 **`~/.agentear/commands.json`**。**不存在时给一份开箱默认表**;
坏文件会报错,而不是静默退回默认(静默退回会让你以为自己的指令还在)。

## 动作只有三种,故意不给 shell

| 动作 | 干什么 |
|---|---|
| `builtin` | 切音色 / 切语气 / 切模式 / 存笔记 |
| `open_url` | 浏览器打开,`{rest}` = 短语后面的内容、`{text}` = 整句 |
| `http_post` | POST 一个 JSON 到**你自己的** webhook(Notion / n8n / Zapier / 自建) |

**不执行 shell。** 语音识别错一个字就变成在你机器上执行命令,而且**没有撤销键**。
`open_url` 只允许 `http` / `https` / `mailto`,`file:` 之类一律拒绝;
「发邮件」用 `mailto:` **打开草稿让你确认** —— 误识别的代价是草稿,不是已发出。
槽位是语音听出来的任意内容,填进 URL 前会转义(`&` 不会凭空变成新参数,`#` 不会吃掉后半段)。

## 怎么加指令

```bash
agentear --commands                      # 列出当前指令表
agentear --add-command "记一下"           # 加一条(--action builtin|open_url|http_post)
agentear --add-command "查文档" --action open_url --url 'https://devdocs.io/#q={rest}'
agentear --add-command-wav my.wav        # 录一句定义:先 ASR 成短语,再写进表
agentear --match-command "搜索 talk.rs"   # 干跑:只报命中和槽位,不执行任何动作
```

菜单栏新增**「打开指令表」**,直接开那个 JSON —— ASR 会把短语听错,
**文件必须能改**,否则你会得到一条永远匹配不上的指令。改完用 `--match-command` 先验一下。

## 这轮抓出来的一个真 bug

`--match-command` 这个干跑入口**当天就抓到**:槽位原本取自**归一化后的句子**,
于是「帮我搜代码 talk.rs」的槽位变成 `talkrs` —— **点没了、大写也没了**,
搜索和记事都跟着变形。

更值得记的是:**当时的测试把这个坏行为钉住了**(`rest == "rustasync"`),
断言看着还挺像那么回事。现在槽位取自**原文**,只把首尾标点修掉;
**归一只用来判断命中**。

## ⚠️ 一个要知道的行为变化

**指令表在两种模式下都会触发,不限对话模式。** 这是有意的:
「切换到对话模式」这条内置动作**只有在输入法模式下说才有意义**,
锁进对话模式等于把它废掉。

**代价**:输入法模式下说了一句「恰好以某个已声明短语开头」的话,它会**顺手多干
一件事**(开浏览器 / 记一条 / 切音色)——**但文字照样进剪贴板、照样上屏,
一个字节都不会丢**。默认表的短语故意写得具体(「搜索」「帮我搜」「发邮件给」
「记一下」),而不是「打开」这种半句话。

**不想要就把 `commands_enabled` 设为 `false`**(默认 `true`)。

## 其他

- 配置 `commands_enabled`,**默认开**。开着的代价只是「多查一次字符串前缀」。
- `cargo test` 238 → **268 passed / 0 failed / 6 ignored**;clippy 与上版持平(8 条既有警告)。

## 说清楚没做到的部分

- **不做繁简归一**:没有离线表,所以「記一下」和「记一下」算两条。
  **不要读成「中英泰繁简都行」。**
- **误触发率没测**。短语很短时(比如「打开」),正常对话里也可能被它抢走
  —— 要统计这个得攒一批自然语句,还没做。
- **`--add-command-wav` 只定短语**,动作还得用 `--action` 指定。
  「录一句 → 建一个 http_post 动作」的一步到位没做。
- 实时通话那条路的边界**一条没变**:推键式打断、**AEC 未解决**、不是全双工;
  **音色仍未经人耳验收**(详见 v0.8.1 说明)。

## 安装

下载 `AgentEar-0.9.0-macos-arm64.zip`,解压后把 `AgentEar.app` 拖进「应用程序」。

**要求 Apple Silicon Mac(M1 及以上)**。首次启动要各授权一次**麦克风**与
**辅助功能**(TCC 权限不会从终端带到 .app,两者是独立主体)。
