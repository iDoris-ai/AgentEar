## 这版加了「说话」三栏 + 一堆诚实的实测结论

### 1. 菜单栏 → **说话** → 语系 / 语气 / 音色

| 栏 | 选项 |
|---|---|
| **语系（方言/口音）** | 普通话、粤语、河南话、四川话、山东话、东北话、天津话、英语、英式英语、美式英语、加拿大英语、泰语 |
| **语气** | **亲切自然（默认）**、平静温和、活泼明快、沉稳专业 |
| **音色** | **扫音色库目录**（你把自己的 `my.wav` + `my.json` 丢进 `~/.agentear/talk/voices/` 就能选） |

点一下立刻生效（下一轮就变），不用重启任何东西。

### 2. 语气为什么默认是「亲切自然」——实测挑的

| 配置 | 耗时 | F0 起伏 | 能量起伏 |
|---|---|---|---|
| 只写语种 | 3.90s | 3.53 半音 | 0.0736 |
| **加情绪描述** | **2.73s** | **5.57** | **0.1196** |
| 情绪 + steps=5 | 1.46s | 4.10 | 0.0630（最平） |
| 情绪 + steps=20 | 5.54s | 4.50 | 0.1012 |

**两条结论**：① 加情绪描述免费且显著（+58%/+62%）；② **`inference_timesteps` 不要降档**——降到 5 只快 1.9 倍却明显变平，升到 20 只更慢。**默认 10 是甜点。**

### 3. `/health` 现在自报峰值 RSS

`peak_rss_mb` 由进程自己用 `resource.getrusage` 报——macOS 沙箱里读不到别的进程内存，而仓库规矩是「高资源档的峰值 RSS 必须实测入库」。**实测：4bit 2386MB / 8bit 3266MB。**

### 4. ⚠️ 关于「声音像机器人」——我做了什么、以及我没能证明什么

**你反馈之后我做的排查（都写在这里，包括失败的部分）：**

- 我原来挑参考音频时只看了音高/浊音帧/RMS，**把"活"挑没了**：旧参考本身 F0 起伏只有 2.75 半音。
  已重造 `female_zh_02`（起伏 4.22 半音、F0 174.5Hz 更自然），并改成**以起伏为主项**来打分。
- 试了 8bit 模型对比 4bit（多 880MB）：**输出差异在噪声里**（F0 起伏 3.98/6.50 vs 5.04/5.07）。
- **我没能证明哪个配置更"像人"**：run-to-run 波动和配置间差异一样大——同一配置两次实验给出
  5.57 / 4.55 半音（n=2~3）。**用这种量去调音色等于在噪声里找信号。**

**所以这版不替你下结论，把候选摆出来让你听**：

```bash
scripts/preview-voices.sh          # 生成 8 个候选并逐个播放；告诉我编号就行
```

**最可能真正解决"机器人感"的一条（也是我建议你先试的）**：**拿一段真人录音当参考**。

```bash
# 录 10 秒你自己的（或任何人的）声音，安静环境、正常语速
~/.agentear/llm/venv/bin/python services/tts/make_voice.py \
  --model ~/.agentear/talk/models/voxcpm2-4bit \
  --from-wav ~/Desktop/my_voice.wav \
  --out ~/.agentear/talk/voices/my_voice.wav
```

**为什么这可能更有效**：我现在的参考是**模型自己生成的**（自举），合成感会被克隆再放大一层。
真人录音没有这个问题。
