## v0.25.0 —— 能真正附着到 Agent24 了（AgentEar 这一侧；独立版行为不变）

**独立使用 AgentEar 的人：这一版什么都没变。** 不点「连接 Agent24」，就不会连任何东西、
不发任何事件——输入法模式、对话模式、自带小模型、提示音、指令表，全和 v0.24.0 一样。

这一版是「嵌入 Agent24」的第二步（M6 / T6.1.2，P2 的 AgentEar 侧）：v0.24.0 把 AgentEar
改成了可插拔宿主、用假宿主测透；这一版**写出了真正连 Agent24 的那一段**。

### 新增

- **设置 →「连接 Agent24」**（jason 拍板 Q2=b：一键配对）
  - AgentEar 替你在后台跑 `agent24 os attach add`，拿到的凭据存进 **macOS 钥匙串**
    （不写进 `config.json`，也不进日志）。
  - 找 `agent24` 命令的顺序：设置里指定的路径 → `~/.agent24/bin/agent24` → PATH。
  - 设置里显示连接状态：未配对 / 连接中 / 已连接 / 未连上（独立模式运行、会自动重连）/
    已断开停听 / 需要处理（配对失效、版本不兼容、在 Agent24 里被停用、权限变更要去 Agent24 确认）。
  - 需要处理时按钮会变回「连接 Agent24」，点一下就是重新配对。
  - 「断开 Agent24」= 在 Agent24 那边撤销 + 删掉钥匙串里的凭据。
- **连上之后**，AgentEar 作为 Agent24 的耳朵和嘴巴：
  - 对话模式的转写、轮次状态、播报状态、错误报给 Agent24（输入法模式不报转写）；
  - 回答由 Agent24 的本地模型给（`local_only`，不出本机）；Agent24 没授予模型时，
    若你的独立模式用的是本机小模型就继续用它，否则只转写不回答——**绝不改走可能出本机的路径**；
  - Agent24 可以让 AgentEar 说一句话（排在当前回答之后），也可以让它停下。
- **断开之后**（Agent24 退出 / 重启）：按你之前定的规则（B5），独立模式用的是本机小模型就自动回到独立模式，
  否则停听并提示；后台自动重连（1 秒起、翻倍、最多 30 秒一次），重连后是新会话。
- **菜单栏 →「恢复独立模式」**：只在「断开且停听」时出现，一键回到独立模式。
- **升级不用重新配对**：附着用的 manifest 有自己的修订号，不跟 AgentEar 版本走；
  真要改了（比如以后加能力），AgentEar 会自动重新注册——**放宽隐私的变更除外**，那种要你在 Agent24 那边确认。

### 修复

- **断开 Agent24 时，还没发出去的事件不再发往旧连接**（v0.24.0 PR #96 评审发现）：原来断开只停了收新事件，
  已经排队的那些仍会被投递到旧宿主；换新连接时旧队列也可能挤在前面。现在断开 / 重连会作废旧队列，
  新连接只收到新会话的事件。

### 协议

按 Agent24 的 A3 设计 v2（Agent24 PR #524 @68c2412）**独立实现**，不依赖 Agent24 的代码：
Unix socket + 一行一个 JSON-RPC 帧，握手、事件、模型回调、取消、反向命令、断连处置表都按文档来。

### 验证

- `cargo test` 440 + 4 + 8 通过、0 失败。A3 客户端 27 条测试跑在**真 Unix socket** 上，对面是一个
  只按规格写的假内核（握手各种拒绝、没授予模型、限流、取消、反向命令、超长帧、断线重连新会话……）。
- 关键判据做了 12 处调用点变异，全部被测试抓到。
- 命令行 `--talk-turn <wav> --host a3` 对假内核实跑了完整一轮：转写 → 本地模型回答 → 播报 →
  宿主让它再说一句（排在回答之后）→ 开始 / 完成都报回去，0 条校验失败。
