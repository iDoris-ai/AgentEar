## 这版改了什么

### 1. 双击窗口从 350ms 放宽到 **500ms**

你双击「感觉反应不对」——日志里找到了原因：

```
11:28:00.959  → 右 Command 轻点（119ms）
11:28:01.963  → 右 Command 轻点（103ms）      ← 两下相隔 1004ms
```

那两次相隔约 **1 秒**，而当时的窗口是 **350ms** —— 被判成两次独立单击(开一下、停一下),
于是「录音过短丢弃」,你的感受就是「双击没反应」。

现在把窗口对齐 **macOS 自己的双击判定**(`NSEvent.doubleClickInterval` 默认 500ms)——
用户的肌肉记忆就是按那个训练的,比它更紧等于要求你「比双击应用程序图标还快」。

⚠️ 说实话:**500ms 仍然快于你那次的 1004ms**。双击时两下要**干脆一点**
(像双击图标那样),不要「点一下、顿一下、再点一下」。这条已经写进回归用例,
免得以后有人把窗口放到 1 秒去迁就——1 秒的窗口会把正常的两段录音吞掉。

### 2. 菜单栏加了一个模式小标记

你要的「后面有个小就行」:

| 模式 | 菜单栏图标 |
|---|---|
| 输入法(默认) | `🎙` |
| 对话 | `🎙💬` |

**只在非默认档加符号**——默认状态不该也多背一个字符,而菜单栏寸土寸金。
标记放在后面,是因为前面那个 🎙 表达「我在录音」这件更急的事,不能因为切模式就被挤走。

## 关于「菜单怎么默认成了对话模式」

**那是你机器上的配置被固化成 `conversation` 了**,不是默认值——产品默认一直是输入法。
我已经把它改回 `input_method`(用 `--diagnose` 能看到 `talk_mode = input_method`)。

## 升级要怎么操作

**退出再启动一次**(菜单栏 → 退出,然后重新打开)。运行中的进程用的是启动时那份二进制,
文件换了它也不会变。

启动后可以看到:
- 菜单栏图标是 `🎙`(输入法)
- 菜单里第一栏是「模式: 输入法」
- 单击 → 输入法;双击(500ms 内) → 对话,图标变成 `🎙💬`

日志里每次轻点都会打分类结果:`→ 右 Command 轻点（120ms）→ Single/Double`,
想确认手感就用 `./target/release/agentear --debug-keys`。
