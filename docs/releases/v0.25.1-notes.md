## v0.25.1 —— 两处小修（#97 评审的非阻塞项；独立版行为不变）

**独立使用 AgentEar 的人：这一版什么都没变。**

### 修复

- **「连接 / 断开 Agent24」按钮不再可能永久灰掉。** 配对/撤销在后台线程里代跑 `agent24` CLI；
  以前如果这段代码 panic，「正在进行」的标志不会复位，按钮会一直灰到重启 AgentEar。
  现在用一个 drop guard 保证：无论正常结束还是 panic，标志都会复位（`tray::spawn_busy`）。
  目前生产路径上没找到会 panic 的点，这是兜底。
- **发给 Agent24 的请求里，数组中的对象也会去掉值为 null 的可选字段**（`a3::strip_nulls`）。
  以前只处理顶层与嵌套对象，没进数组。当前唯一调用点（模型请求）打不到这个缺口，
  属于把函数语义补完整；数组里本身为 null 的元素仍然保留（那是值，不是省略的字段）。

### 验证

- 新增 3 条单测：`strip_nulls_recurses_into_array_elements`、
  `busy_flag_resets_even_when_the_job_panics`、`busy_flag_rejects_a_second_job_while_running`。
- 调用点变异：去掉数组分支 → 第一条变红；把 guard 换回「末尾手写复位」→ panic 那条变红。
