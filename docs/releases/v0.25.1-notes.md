## v0.25.1 —— 两处小修（#97 评审的非阻塞项；独立版行为不变）

**独立使用 AgentEar 的人：这一版什么都没变。**

### 修复

- **「连接 / 断开 Agent24」按钮不再可能永久灰掉。** 配对/撤销在后台线程里代跑 `agent24` CLI；
  以前如果这段代码 panic，「正在进行」的标志不会复位，按钮会一直灰到重启 AgentEar。
  现在用一个 drop guard 保证：无论正常结束还是 panic，标志都会复位（`tray::spawn_busy`）。
  目前生产路径上没找到会 panic 的点，这是兜底。
- **发给 Agent24 的请求里，数组中的对象也会去掉值为 null 的可选字段**（`a3::strip_nulls`）。
  以前只处理顶层与嵌套对象，没进数组。当前唯一调用点（模型请求）打不到这个缺口，
  属于把函数语义补完整；数组里本身为 null 的元素仍然保留（那是值，不是省略的字段）。

### 配对前的兼容检查改为能力探测（不再看版本号）

- 点「连接 Agent24」时，AgentEar 先跑一次 `agent24 os attach list --json`：退出码 0 且输出是
  `{"modules":[...]}` 才认为这个 Agent24 支持附着模块；否则提示「你的 Agent24 版本还不支持附着模块，请升级」。
- 原因：Agent24 在 ME4 期间没发版，`agent24 --version` 一直报 0.3.0，而 A3 已经在里面了——
  按版本号挡会把能用的 CLI 拒掉。版本号现在只作为日志里的附加提示（≥0.5.0 显示「正式版已支持」）。
- 探测只在「点连接」和「升级后 manifest 变了要自动重新注册」时各跑一次（没有常驻 daemon 时 CLI
  会临时拉起一个再收掉，所以不在任何重连循环里调用）。删掉了原来 `(0,0,0)` 的占位版本闸。

### 与真 agent24d 的端到端（测试设施，不影响产品行为）

- 新增 `scripts/e2e-agent24.sh`：隔离 HOME / 数据目录，起真 agent24d、注册、附着跑一轮、反向命令、
  用量与隐私（外部计数桩 = 0）、负测（本地模型不可用时失败关闭）、撤销。
  对 Agent24 未合并的 A3 分支（#532@`b111ac4`）预跑 **29/29 全过**，证据在 `docs/data/e2e-agent24-2026-09/`；
  **Agent24 合并后还要对它的 main 复验一次**。
- 仅供测试的环境变量 `AGENTEAR_A3_LINGER_SECS`（缺省 0 = 行为不变，上限 120）：
  `--host a3` 跑完一轮后连接多保持几秒，好让脚本从宿主外部送 `speak` 命令进来。

### 验证

  `busy_flag_resets_even_when_the_job_panics`、`busy_flag_rejects_a_second_job_while_running`。
- 调用点变异：去掉数组分支 → 第一条变红；把 guard 换回「末尾手写复位」→ panic 那条变红。
