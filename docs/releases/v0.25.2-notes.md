## v0.25.2 —— 附着 Agent24 时不再把「思考」念出来

**独立使用 AgentEar 的人：这一版什么都没变**（边车路径早就关了思考，`max_tokens` 仍是 160）。

### 修复（jason 2026-09-27 真机抓到）

连上 Agent24 后，宿主把对话请求路由到了 **Qwen3-8B-4bit**——一个会先「想一想」的模型。
它的输出**不带 `<think>` 开头标签**（Qwen3 的聊天模板把开头标签放在了 prompt 里），
思考写到一半就用完了 160 个 token 的上限，连结尾的 `</think>` 都没到。
我们原来的过滤只认「成对的 `<think>…</think>`」，于是整段内心独白
（「好的，用户让我讲个笑话。我需要先确认……」）被当成回答念了出来，一念 36 秒。

- **请求里关掉思考**：附着路径发给宿主的问题末尾加上 Qwen3 官方的软开关 ` /no_think`。
  宿主的推理接口不收模板参数，这是 AgentEar 能关掉它的唯一办法；对别的模型只是一段无害的文字。
  **实测**（隔离的 agent24d + 本机 oMLX，Qwen3-8B-4bit，同一句「今天天气怎么样」）：
  修复前 136 个 token（先想一阵）；修复后 3 次都是 **22 个 token**，直接给答案。
- **认得「没有开头标签的思考段」**：第一个 `</think>` 之前没有 `<think` 时，它之前的全算思考，
  一起丢掉（`talk::strip_thinking`，所有推理路径通用）。
- **被截断在思考里就不念**：用满了上限、却没看到 `</think>` 时，手里那段只能是没想完的思考，
  这一轮改念一句「这个问题我没想明白，换个说法再问我一次吧」（中/英/泰），
  并向 Agent24 报一条 `error{code: internal, message: reasoning_truncated}`。**宁可不说，不念独白。**
- **附着路径的上限 160 → 512**：万一模型不理 `/no_think`，给它想完留出余量；
  念出来的只有剥掉思考后切好句的正文，上限变大不会让回答变长。

### 没做的
- **idoris 那一档没加 `/no_think`**：那一档是 OpenAI 兼容请求，应该用正规的模板参数关思考，
  而不是往用户的话里塞字——等真接 iDoris 时再定。
- **流式路径**（边车/idoris）如果换成会思考、且不关思考的模型，没有开头标签的思考段在
  `</think>` 到达之前可能已经被切句念出去了。边车默认用 `enable_thinking: false` 关着，
  所以现在碰不到；换模型时要注意。
