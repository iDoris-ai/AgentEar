## v0.24.0 —— 为嵌入 Agent24 做好内部准备（独立版行为不变）

**独立使用 AgentEar 的人：这一版什么都没变。** 输入法模式、对话模式、自带小模型、
提示音、指令表，全都和 v0.23.1 一样。默认配置下没有任何新行为。

这一版做的是「嵌入 Agent24」的第一步（M6 / T6.1.1，P1 骨架）：把 AgentEar 内部改成
**可插拔宿主**，让它以后既能独立跑，也能附着到 Agent24 当它的耳朵和嘴巴。
**附着能力还没接真实宿主**——Agent24 那边的 A3 附着协议冻结之后（P2）才接；
这一版只用进程内的假宿主把规则测透。

### 新增（默认都不生效）

- **对话 LLM 三档可选**（`talk_llm_transport`，jason D3）：
  - `sidecar`（默认）：本机边车，和以前一样；
  - `idoris`：直连 iDoris 网关（`idoris_url` / `idoris_model`），
    请求带 `X-iDoris-Privacy`，**默认 `local_only`**，要出本机必须显式写 `idoris_privacy: "any"`；
  - `agent24`：经 Agent24 的 `_a24/model/complete`（非流式）。**没附着时这一档如实失败，
    不会偷偷退回本机边车。**
  - 附着到 Agent24 时一律经宿主推理，不看这一项。
- **断开 Agent24 之后怎么办**（`attach_fallback`，B5，jason 2026-09-27 拍板）：
  独立模式的推理在本机 → 自动回独立模式；否则（比如配成直连 iDoris）→ **停听并提示**
  （菜单栏标题多一个 🔌，按键时用 `say` 念一句）。设成 `stop` 则一律停听。
- **附着时的规则**（已与 Agent24 会话约定）：
  - 只有对话模式的转写报给宿主；输入法模式不报，但命中指令表产生的提案照报；
  - 向外动作（打开网页、发邮件、webhook）**AgentEar 只提出、不执行**，确认也交给宿主
    （`confirm_reply` 事件；说「确认」或短按录音键 = 确认，说别的一律当拒绝）；
    本机可逆动作（切语系 / 语气 / 模式、记一条）仍在本地执行；
  - 宿主让 AgentEar 播报的内容排在当前回答之后；按录音键或宿主发 stop 都清空排队；
  - 宿主返回「出过本机」的回答而本模块声明只许本地时，**不念**，报隐私违例；
  - 事件在后台串行投递，**不会卡住按键**；单个字符串超过 8 KiB 截断并标注；
    给宿主看的文件路径不带用户名；**音频和音频路径永不出现在任何事件里**。
- **命令行**：`--talk-turn <wav> --host fake`、`--run-command <文本> --host fake`
  用进程内假宿主跑一轮，把宿主收到的事件逐行打出来。

### 修了什么

- `--match-command --json`（给宿主用的冻结契约入口）在**没有装 ASR 的机器上也能用了**。
  原来它排在 ASR 依赖检查之后，会直接报「缺少 ASR 依赖文件」退出。
  纯文字的子命令（`--match-command` / `--commands` / `--run-command` / `--say` / `--ask` / `--cue`）
  现在都跳过这项检查；守护进程和需要转写的子命令照旧先检查。
- 回环地址判断改成按 IP 真解析：`127.0.0.1.evil.com` 这种以 `127.` 开头的域名
  不再被当成本机（测试当场抓到的）。

### 验证

- 新增 51 条单测（宿主适配层 42 条 + 守护进程接线 7 条 + 传输层 2 条），外加 1 条手动用的
  实测事件校验（默认忽略）；全量 `cargo test` 413 + 4 + 8 通过、0 失败。全部不启动守护进程、
  不出声、不连网、不碰真实数据目录。发出的每一种事件都用 `contracts/` 的 schema 校验；
  命令解析器与命令 schema 双向对照（合法的都收、非法的都拒）。
- 调用点变异 14 处（附着时不走宿主分支、别的话当成确认、路径不去用户名、短按不归宿主、
  不做隐私自检、音频路径能混进事件、命令不去重、不校验命令名、断连一律回独立、
  事件同步阻塞、不截断长字符串、少发阶段事件、回环按前缀猜、模型请求带 privacy），
  **每一处都有测试变红**。
- 用假宿主跑命令行实测：一轮对话、发邮件（确认 / 取消 / 说别的）、本地指令，
  打出来的事件用 schema 逐条校验通过。

### 没做 / 没测

- **没接真实的 Agent24**：A3 附着协议（注册、token、握手、重连）等 Agent24 侧冻结后在 P2 做。
- 附着模式下的首字起播会比本机流式慢（宿主推理回调不做流式，整句路径实测中位数 4.86s，
  本机流式 2.80s）——这是已拍板的「P2 先上非流式」的代价。
- 菜单里「恢复独立模式」的入口还没加（停听状态现在只能等宿主回来或改配置），P2 一起做。
