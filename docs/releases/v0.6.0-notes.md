## 这版加了什么

**能对话了。** 按一下录音键说一句，松手后它会用语音回答你——**ASR → 本地大模型 → 语音合成 → 播放**整条链路都在本机跑完，不经过任何第三方服务器。

不是"语音助手"那种云端来回，是**打电话式的**：回答正在播的时候你再按一下键，它会**立刻掐掉自己的声音**开始听你说。

## 具体换了什么

- **TTS 换成 `mlx-community/VoxCPM2-4bit`**（Apache-2.0，48 kHz）。这是 ADR-0007 §6 里唯一能说泰语的候选。macOS 自带的 `say` 降级为**零依赖保底**（`--backend say`），不装模型也能出声。
- **推理默认面壁 MiniCPM5-2B**（4bit MLX，1.4 GB）。**模型可换**——`talk_llm_url` 指向任何 OpenAI 兼容端点即可，Rust 侧一个字不用改。另有一个零依赖的 `mock` 引擎（必须显式配置才启用），用来在没有模型时证明链路通。
- **中英泰三语**都能跑完整一轮：ASR 逐字正确，回答语言跟着 `talk_lang` 走。

## 怎么用

```bash
scripts/setup-talk.sh        # 首次：下两个模型（约 3.5 GB，不随包分发）
scripts/serve-talk-llm.sh    # 起 LLM 边车   → 127.0.0.1:8794
scripts/serve-tts.sh         # 起 TTS 边车   → 127.0.0.1:8765
```

然后在 `~/.agentear/config.json` 里把 `talk_enabled` 打开（默认关），按录音键说话。

**不开 `talk_enabled` 的话，行为和 v0.5.0 完全一样**——这一版所有新增配置项都默认关或指向本机默认端口。

不想开麦也能验：

```bash
./target/release/agentear --ask "今天天气怎么样"          # 文字进 → 语音出
./target/release/agentear --talk-turn q.wav --lang zh    # 完整一轮，不走麦克风
./target/release/agentear --diagnose                     # 会告诉你两个边车在不在
```

## 实测

`docs/benchmarks-talk.md`（新增）：三语端到端、回环转写证明语种正确、时延与内存。热态一句回答约 4–7 秒（ASR 0.1–0.5s + LLM 0.7–0.9s + TTS 合成 2.6–5.1s + 播放）。

## ⚠️ 这一版**没有**做的事（别读成做过了）

- **AEC（回声消除）没做。** 推键式绕开了它，但它本身没解决：外放时系统仍可能听见自己。**VAD 自动打断、双讲、误打断率、端到端打断延迟 <300ms 全部未测。**
- 这是**打断式半双工**，不是全双工——解决"说完才轮到我"，不解决"一边听一边想"。
- **没有产品入口**：没有起/停一次通话的按钮，要走配置 + 命令行。
- **MiniCPM5-2B 的泰语在能力边界外**（模型卡只声明 en/zh）：实测出现过夹英文词、以及把问句原样退回来的情况（后者已挡住，不播）。要稳就得换模型。
- 4bit 与 bf16 的质量对比没做；天气那句话是**本地写死的场景，不是天气接口**。
- 人耳验收没做。

## 顺带

修掉了一条身份长期未知的不稳定测试（FU-16）：根因是两个模块的测试临时目录相撞——macOS 时钟分辨率约 1 µs，实测连续两次取值相同占 91.6%。改为进程内计数器后，全量 `cargo test` 连跑 30 次 0 失败。

测试：`cargo test` 239 passed / 0 failed / 6 ignored；TTS 服务 34 passed；clippy 8 条既有警告（无新增）。
