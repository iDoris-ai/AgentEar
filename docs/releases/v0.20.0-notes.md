## v0.20.0 —— 开机自动启动 + 原生设置窗口

两件事都是 jason 拍板要的（PR [#85](https://github.com/iDoris-ai/AgentEar/pull/85)）：
一个让它装完就常驻，一个把越来越长的菜单收拾干净。

### 1. 开机自动启动（**默认开**）

普通用户不会去「系统设置 → 登录项」里翻，装完就该是能用的常驻状态。

- 开着时写 `~/Library/LaunchAgents/ai.idoris.agentear.plist`，关掉时删掉它。
  开关在**设置窗口**里，点一下立刻改文件。
- **只写/删文件，不调 `launchctl bootstrap` / `bootout`**，所以**下次登录才生效**，
  不影响当前正在跑的这个实例。早期版本调过 launchctl，codex 复查抓到两个真 bug：
  开启时会**立刻复制出第二个实例**，关闭时**可能把当前进程杀掉**。所以改成了只动文件。
- **只对正式安装的 `.app` 生效**：开发时的裸二进制、以及 App Translocation 的临时路径
  （没从「下载」里挪出来就直接打开时，系统会把 `.app` 挂到一个随机临时目录）
  都会被识别出来并跳过，日志里写一行原因。否则 plist 会指向一个下次登录就不存在的路径。
- 守护进程**每次启动都会对账一次**（内容没变就不写），用户点开关也会触发。
  两个调用点**持同一把锁、各自现读配置**，保证最后落盘的是当前最新的选择。

⚠️ **升级用户注意**：旧的 `config.json` 里没有 `launch_at_login` 这个键，
按默认值算就是**开**。所以从 `.app` 升级到这一版后，**第一次启动就会写入登录项**。
不想要的话，到设置窗口里关掉即可。

### 2. 原生设置窗口

菜单栏原来那一长串（技术术语纠错 / 边车状态 / 保留期 / 术语表 / 指令表 /
数据目录 / 日志）挪进了一个独立窗口。顶层菜单只保留到「自动上屏」，
后面接「设置…」和「退出」。窗口已经开着时再点「设置…」，
会把它调到前台并按最新配置重建内容。

### ⚠️ 验证边界（如实说明）

- **没有做真实点击验收。** 这台机器上一直跑着 jason 在用的 v0.19.0。
  新 build 用的是同一个签名身份，两个同时跑会抢同一个全局热键和同一份 `config.json`，
  会打断用户手头的工作，所以没做。
  **升级后建议人工过一遍**：
  ① 打开「设置…」，每一项都点一下；
  ② 关掉开机自启，确认 plist 被删掉；再打开，确认 plist 写回来了；
  ③ 注销后重新登录，确认自动起来、而且**只起了一个**。
- AppKit 方法签名是对照 `objc2-app-kit` 0.3.2 源码逐个核对的，**不是在
  macOS 11–13 真机上跑出来的**。
- v0.19.0 那条「播放期间按录音键打断」的修复，同样**还没在物理键盘上实测**，
  这一版没有变化。

### 已知边界（未变）

- **V1 打断方式已定为推键式长期终态**（jason 2026-09-20 拍板、2026-09-25 再次确认）：
  用户按录音键就先掐掉播放。**不做 VAD 自动打断，也不做双讲。**
  这是半双工，**不是「体感接近全双工」**。
- **推键式录音在进程崩溃时会丢掉整段还没提交的录音**（最长 300 秒）。
  这条风险**待 jason 决定**，见 ADR-0007 §4.5。
- **泰语在 MiniCPM5-2B 的能力边界外**，实测不稳定。
- 方言正不正宗**只能靠人耳验收**。那一栏只是开关，不能把普通话变成方言。
- ⛔ 职责边界（ADR-0008）：命令执行、确认 UI、回执展示归宿主 Agent24。
