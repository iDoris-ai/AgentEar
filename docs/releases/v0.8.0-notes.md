## 这版治的是你说的「声色和声量都飘忽不定」

### 根因（实测，不是猜）

VoxCPM2 是**零样本**模型：不给参考音频时，它**每次生成都重新随机采样一个说话人**。
而且输出**没做响度归一**。同一句话生成三次，实测：

```
F0 中位   250.7 / 142.2 / 285.7 Hz     ← 有一次落在男声带
RMS      0.1999 / 0.0659 / 0.0440      ← 音量差 4.54 倍
```

这正是你听到的两件事。

### 改了什么

| 改动 | 效果（实测） |
|---|---|
| **响度归一**（目标 −20dBFS，峰值上限 0.97，只做整句增益不做压缩） | RMS 波动 **4.54× → 1.00×** |
| **参考音频钉音色**（`ref_audio` + `ref_text`，克隆模式） | 不再出现男声带样本；说话人不再每句一换 |
| **语系/风格**（`style`） | `zh` / `yue`(粤) / `henan`(河南) / `sichuan` / `shandong` / `dongbei` / `tianjin` / `en` / `en-gb` / `en-us` / `en-ca` / `th` |
| **`make_voice.py`** | 造参考音频：生成候选 → 按 F0/浊音帧/RMS 打分 → 挑最好 → **用本仓库 ASR 转出 ref_text** |

默认女声是 `female_zh_01`（自举出来的：6 个候选都在女声带，挑中音高最接近 190Hz、
浊音帧最多、RMS 最高的那条）。`/health` 会报 `default_voice` / `voices` / `styles`。

### ⚠️ 三条必须说清的边界

1. **MLX 版 VoxCPM2 没有实现 `seed`**（我把源码翻了一遍，文件里没有任何 seed 处理）。
   官方 PyTorch API 和 llama.cpp-omni 的 `--seed` 才有。所以**别再试「传固定 seed 稳定音色」**——
   实测传了完全无效。这里的可复现性来自参考音频。
2. **我的 F0 量具在真实语音上不可靠**，所以「音高还抖多少」**我不给结论**：
   第一版有倍频错误（真实语音里二次谐波常比基频强，会把 F0 高估约 2 倍），
   修补后又发现次谐波阈值卡在 80% 时仍会偶尔跳。**要定论得用正经 pitch tracker 或说话人嵌入**
   （`speech embed-speaker`，需要联网下模型一次，沙箱里跑不了）。
   **能确定的只有响度那一条**（直接量能量，无歧义）。
3. **方言对不对没有客观判据**（`language-id` 只到语言级）。`style=yue` 是「让模型朝粤语走」，
   不是「已验证粤语」。**只有人耳能收口。**

### 你怎么验

```bash
curl -s http://127.0.0.1:8765/speak -H 'Content-Type: application/json' \
  -d '{"text":"今天清迈天气还不错","lang":"zh"}' -o a.wav
curl -s http://127.0.0.1:8765/speak -H 'Content-Type: application/json' \
  -d '{"text":"今日天氣唔錯","lang":"zh","style":"yue"}' -o b.wav   # 粤语
curl -s http://127.0.0.1:8765/health | python3 -m json.tool        # 看有哪些音色/语系
```
