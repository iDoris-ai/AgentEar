## v0.26.0 —— 每一轮都能看到「慢在哪一段」，并且落盘积累

jason 2026-09-27：本地模型的两大卖点是**隐私**和**快**，所以每次回答都要能看到耗时（毫秒级），
而且要**落盘积累**，作为以后定位慢点的调试依据。

### 分段（t0 = 松开录音键）

| 字段 | 含义 |
|---|---|
| `record_ms` | 录音时长（按下→松开） |
| `asr_ms` | 松键 → 转写完成（含 raw 落盘） |
| `llm_first_ms` | 转写完成 → 模型第一个字（只有流式才有） |
| `llm_ms` | 转写完成 → 模型全文返回 |
| `tts_first_ms` | 第一段 TTS 合成本身的耗时 |
| `to_first_audio_ms` | 松键 → 第一声（**端到端「说完到听到」**） |
| `play_ms` | 第一声 → 播完（被打断时是实际播出长度） |
| `total_ms` | 松键 → 这一轮结束 |

另带 `llm_via`（sidecar / idoris / agent24）、`model`（宿主推理带 model_id）、`tier`（local / remote）、
`asr_backend`、`prompt_tokens` / `completion_tokens`、`interrupted`。**缺了的段省略，不填 0**——
0 ms 是一个「很快」的测量值，拿它顶替「没测到」会把中位数往下拉，那是在报喜。

### 在哪能看到

- **菜单栏**：版本号下面一行「上一轮：说完→出声 2.81s（ASR 0.13s / 模型 0.87s / 合成 1.65s）」（中/英/泰）。
  只显示真的出了声的那一轮。
- **日志**：每轮一行「本轮耗时（conversation/ok）：说完→出声 …｜ASR …｜模型 首字 … 全文 …｜合成首段 …｜播放 …｜合计 …｜经 …」。
- **落盘**：`<数据目录>/derived/timings.jsonl`，一轮一行，**只有数字与枚举**，不存转写、回答、音频路径
  （测试钉住：落盘的键集合是白名单）。超过 10 MB 滚动为 `timings.1.jsonl`。输入法模式的轮次也记（只有 ASR 段）。
- **统计**：`agentear --timings [--last N]`——按「模式 · 推理路径 · 模型」分组，每段报
  **中位数 / p90 / 最大值** 和样本数 n（仓库规矩：只报这三个数，不报好看的区间；分位数取最近秩、不插值）。
- **给 Agent24**：附着时，收尾的 `turn` 事件（`phase` 为 `idle` 或 `failed`）多一个可选对象 `timings`，
  字段同上。`agentear.event/1` 之内新增可选字段，按 contracts 的版本规则属于兼容加法；schema 与 fixtures 已更新。

### 实测（本机，2026-09-27）

- 独立模式 `--talk-turn`（边车 MiniCPM，流式）：模型首字 0.53s、全文 1.64s、合成首段 1.05s。
- `--host fake`：`turn idle` 事件带 `timings`，含 `llm_via:"agent24"`、`model`、`tier`、tokens。
- 对真实 agent24d（Agent24 main `604e198`）跑 `scripts/e2e-agent24.sh`：**30/0**，新增断言「turn idle 带 timings」。
- ⚠️ 实测当天这台机器 swap 用满（14 GB / 15 GB）、halmos 占满 CPU，**ASR 要 76–256 s**（平时 0.1–0.3 s；
  用已发布的 v0.25.2 复测同一段录音也是 94 s，所以是机器负载，不是本版改动）。
  这恰好说明了这个功能的用处：一眼就能看出是 ASR 这一段慢，而不是模型。

### 顺带修的

- `scripts/e2e-agent24.sh` S5：原来分别给 transcript / thinking / idle 60 / 30 / 90 秒窗口，
  高负载机器上会误报（事件一条没丢、只是晚到）。改为**等这一轮结束**（turn idle/failed 到达或进程退出，
  上限 300 s）再一起断言。

### 边界 / 没做的

- 命令行 `--talk-turn` 没有「松键」这一刻，t0 取开始转写的时刻，也没有 `record_ms`。
- 边车（OpenAI 兼容）路径拿不到模型名与 token 数，这两项只在宿主推理时才有。
- 真按键 + 菜单栏那一行需要 jason 手测（本环境不能起守护进程）。
