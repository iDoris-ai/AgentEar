# 读出来的东西：
#   RSS   —— 逐 MB 复现（694 / 712–713），可以当稳定量用
#   短RTF —— 0.098–0.104，离散 ±3%
#   中RTF —— 0.154–0.213，**离散 38%**
#   长RTF —— 0.142–0.186，**离散 31%**
#
# 38% 与 §3 表里「最快到最慢接近两倍」的模型间差距是同一量级。
# 所以模型之间的 RTF 排名，在没有重复测量取中位数之前不成立。
# 入库那行的 0.208 落在今天三次的范围内 —— 它和今天的数字**没有差异**，
# 第一次只跑一遍就会误读成「今天快了 26%」。
